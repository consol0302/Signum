# Examples

Run `python examples/compare_synthetic.py` after installing Signum to create an
offline comparison gallery for all seven synthetic regression fixtures. Open
`output/showcase/index.html` to inspect the selected frames and their source
timestamps. These examples illustrate selection behavior, not real-world
semantic accuracy or model cost savings.

`real-evaluation.example.json` is the minimal labeled-recording manifest for
`signum evaluate`.

Collection scripts, frozen Claim 180 manifests, provider probes, and research
workflows live in
[Signum Benchmarks](https://github.com/consol0302/signum-benchmarks).
